# Project Template v1.1.0 Stable — Release Notes

Project Template v1.1.0 is the first Stable release of the Git-native, AI-neutral project knowledge and governance system developed through the v1.1 architecture cycle.

## What is stable

The release freezes the RC2 implementation: atomic lifecycle knowledge objects, concise narrative documentation, machine schemas/policies, generated non-canonical views, graph-driven context/task packs, optional blueprints, deterministic validation, Git/HITL governance boundaries, strict frontmatter handling, transactional module activation, filesystem path hardening, and installable packaged machine assets.

## Verification baseline

- 26 regression/adversarial tests passing.
- Clean wheel installation and console entry point verified outside the source checkout.
- Packaged schemas, blueprints, policies, and templates verified in the installed distribution.
- Three adversarial review rounds completed; final review recommended promotion from RC2 to Stable.

## Versioning

Template release: **v1.1.0 Stable**. CLI release: **0.1.2**. Schema version: **1**. These version lines are intentionally independent.

## Next development line

Future changes should target v1.1.x maintenance releases for bug fixes or v1.2 for new capabilities. Stable v1.1.0 should not receive architectural expansion without a new version.

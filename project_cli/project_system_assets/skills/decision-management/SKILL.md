# Decision Management

## Use this skill when

Record, review, activate, supersede, reject or defer a project decision, or connect an open question to its resolution.

## Authority and scope

The configured human approval path owns meaning-changing decisions. Use the installed object schemas and governance policy rather than copying lifecycle rules into this Skill. Never invent an approver, timestamp or approval event.

## Workflow

1. Distinguish discussion, proposal, question and approved decision.
2. Load related objects and impact documents from the prepared context.
3. Preserve replacement, dependency and resolution traceability.
4. Write only the status and approval evidence actually authorized by the task.
5. Validate the graph and report unresolved consequences.

## Non-responsibilities

Do not choose the outcome, self-approve, prioritize product scope, implement the decision, or broaden the task write set.

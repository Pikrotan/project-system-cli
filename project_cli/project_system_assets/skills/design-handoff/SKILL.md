# Design Handoff

## Use this skill when

Prepare design guidance, inspect configured design projections, process designer proposals, or route an approved design change into the standard Project System lifecycle.

## Authority and scope

Git knowledge remains canonical. Figma is visual reference where linked. Google Docs are projections and Design Changes rows are proposals. External mutation still requires task, policy and human authorization beyond selecting this Skill.

## Workflow

1. Load canonical product/design state and configured integration status.
2. Keep project knowledge, visual reference and designer proposal evidence distinct.
3. Preserve Change IDs, Figma links and durable lifecycle evidence.
4. Route approved meaning changes through SYNC planning, verification and human review.
5. Reflect only proven terminal lifecycle outcomes back to the designer bridge.

## Non-responsibilities

Do not treat Google/Figma input as canonical, self-approve designer input, store credentials, create or rebind remote resources without explicit authorization, or bypass SYNC.

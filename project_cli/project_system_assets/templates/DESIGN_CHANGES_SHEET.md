# Design Changes Sheet Schema

Recommended columns:

`Change ID | Date | Author | Type | Area | Screen | Related Screen ID | Related Flow ID | Description | Reason | Logic Changed? | Figma URL | Status | Decision Needed? | Canonical Objects | Commit / PR | Notes`

Designer-facing statuses: `NEW`, `REVIEW`, `APPROVED`, `REJECTED`, `SYNCED`.
A Figma link is a reference, not a textual specification or automatic product approval.
